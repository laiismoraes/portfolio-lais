# 💻 Portfólio Web - Laís Moraes

Este projeto foi desenvolvido como uma atividade do curso de **Desenvolvimento de Sistemas no SENAI**.

A proposta foi criar uma página de portfólio/currículo utilizando **HTML5**, colocando em prática a estrutura semântica, organização de conteúdo, tabelas, links e formulários.

## 🌸 Sobre o projeto

O portfólio apresenta:

- 👩‍💻 Informações sobre mim
- 🛠️ Minhas habilidades
- 💻 Projetos desenvolvidos
- 📋 Tabela com tecnologias e status dos projetos
- 📩 Formulário de contato
- 📱 Informações de contato

Também personalizei o visual com um fundo em **rosa bem clarinho**.

## 🧰 Tecnologias utilizadas

- HTML5
- CSS
